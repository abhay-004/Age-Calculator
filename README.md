# 🎂 Age Calculator

A simple and clean Age Calculator web app built using **HTML**, **CSS**, and **JavaScript**. Enter your birth date and get your age in years, months, and days instantly.

## 🛠️ Features

- Accurate calculation of age in years, months, and days
- Real-time validation for inputs
